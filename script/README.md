# Dossier de scripts du projet OMED

Ce dossier regroupe les scripts et codes sources du projet **OMED** (Gant Musical Interactif).

## Structure

- `app/` : Application mobile / desktop Flutter (interface de contrôle et de communication).
- `esp/` : Code source pour le microcontrôleur ESP32 (gant interactif, capteurs de flexion, etc.).
- `server/` : Serveur Python (gestion de la communication temps réel avec l'application et les périphériques).
